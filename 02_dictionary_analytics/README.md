# Student Score Analytics with Python Dictionaries

This repository contains a Python notebook focused on dictionary operations and data aggregation for student grade management.

# Overview
The goal of this project is to practice managing key-value data structures in Python, iterating through dictionary values, and computing aggregate performance metrics.

# Key Python Concepts
- **Dictionary Initialization**: Storing key-value pairs (Student Name → Test Score).
- **Dictionary Iteration**: Using `.values()` to access and process numerical data.
- **Data Aggregation**:
  - `sum()` — Calculating the total sum of all scores.
  - `len()` — Counting the number of records.
  - Computing the average group score (`total_sum / count`).

# How to Run
1. Open the notebook `02_dictionary_analytics.ipynb` in Google Colab or Jupyter Notebook.
2. Execute the code cells sequentially to view the student score list and the computed group average.
